# Plant Disease Dataset (Image Data)

Comprehensive image dataset for plant disease detection and classification containing **9,374 images** across diverse plant species and disease classes.

## Dataset Structure

The dataset is organized into 	rain and 	est directories categorized by plant species and specific disease conditions.

### Categories & Classes
- **Apple:** Apple Scab, Black Rot, Cedar Apple Rust, Healthy
- **Cassava:** Bacterial Blight (CBB), Brown Streak Disease (CBSD), Green Mottle (CGM), Healthy, Mosaic Disease (CMD)
- **Cherry:** Healthy, Powdery Mildew
- **Corn (Maize):** Cercospora Leaf Spot Gray Leaf Spot, Common Rust, Healthy, Northern Leaf Blight
- **Grape:** Black Rot, Esca (Black Measles), Healthy, Leaf Blight (Isariopsis Leaf Spot)
- **Orange:** Huanglongbing (Citrus Greening)
- **Peach:** Bacterial Spot, Healthy
- **Pepper (Bell):** Bacterial Spot, Healthy
- **Potato:** Early Blight, Healthy, Late Blight
- **Rice:** Brown Spot, Healthy, Hispa, Leaf Blast
- **Squash:** Powdery Mildew
- **Strawberry:** Healthy, Leaf Scorch
- **Tomato:** Bacterial Spot, Early Blight, Healthy, Late Blight, Leaf Mold, Septoria Leaf Spot, Spider Mites Two-spotted Spider Mite, Target Spot, Tomato Mosaic Virus, Tomato Yellow Leaf Curl Virus

## Statistics
- **Total Images:** 9,374
- **Format:** JPG
- **Total Size:** ~127 MB

## License & Usage
This dataset is intended for research, computer vision model training (CNNs, Vision Transformers), and agricultural disease detection systems.
